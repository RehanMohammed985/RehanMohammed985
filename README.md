## How I work

Most people use AI as autocomplete. I run it like a company.

- 🔭 **Research fleets.** When I need to understand a market, I don't read five blog posts. I send out a dozen agents in parallel, each owning a different corner of the internet, and they come back with findings where every claim carries the URL it was verified against. A full competitive landscape, overnight.
- 📚 **Curation agents with rules.** The datasets in my products are built by agents under one hard constraint: nothing enters the data unless the primary source document was fetched and read first. A tracker, a blog, or a model's memory is a lead, never a source.
- 🌙 **Builds that ship while I sleep.** Scheduled agent runs: early-morning builds land on a dev branch, nightly runs test everything twice and release to production. I wake up to a changelog, not a to-do list.
- ⚖️ **The rule that makes it work:** agents propose, evidence decides. Nothing ships on a model's word alone.

## What I care about when building

- **Ship daily.** Momentum compounds faster than planning does.
- **Honest software.** A tool that can't check something should say so plainly, never imply it's fine. Most software lies by omission; mine isn't allowed to.
- **Speed is a feature.** If the answer takes ten seconds, it may as well not exist. I engineer for the first result landing in under two.
- **Solo doesn't mean small.** One person with a disciplined agent workflow can research, build, test, and distribute like a team.
